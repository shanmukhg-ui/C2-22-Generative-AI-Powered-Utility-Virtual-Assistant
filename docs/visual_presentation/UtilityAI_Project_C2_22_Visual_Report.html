Executive Project Overview

UtilityAI (TechBharat C2-22) unifies public utility interactions across municipal jurisdictions. Modern utility portals are plagued by query fragmentation, slow routing, and disconnected call centers. UtilityAI resolves this through a strictly grounded Retrieval-Augmented Generation (RAG) conversational assistant directly docked within a 3-tier Role-Based Access Control (RBAC) dashboard for Citizens, Operations Staff, and Administrators.

System Architecture: Multi-Tier Decoupled Infrastructure Vite • FastAPI • MongoDB Atlas • ChromaDB

Visual UI Representation: Docked Assistant & Dashboard Layout

Unlike conventional floating popup chatbots, UtilityAI features a docked, role-aware AI Assistant panel integrated permanently into the right side of the dashboard (340–380px wide). The left side houses high-density stat cards, operational charts, and ticket tables that dynamically adjust to fit.
